# ECorpNet — откат сервера

Сервер: `192.168.50.116` (MAC `00:25:90:dd:8d:14`), админ `philipp`.

```bash
ssh philipp@192.168.50.116
```

## Три команды

| Команда | Что делает | Когда |
|---|---|---|
| `sudo ctf-snapshot` | Запоминает текущее состояние как «эталон» | Один раз, когда сервер полностью готов. И заново после **любой** своей правки |
| `sudo ctf-restore` | Полный откат к эталону + `ctf-reset` | После своего теста, между раундами, после игры |
| `sudo ctf-reset` | Только игровые данные: БД, флаги, `/srv/reports`, home pnair | Быстрый сброс, если никто не получал root |

**Если сомневаешься — `sudo ctf-restore`.** Его можно запускать сколько угодно раз, занимает ~10 секунд.

## Что делает `ctf-restore`

1. Убивает все процессы игроков: веб-шеллы (весь `ecorpnet.service`), SSH-сессии pnair и всё, что они запустили, включая root-процессы.
2. Удаляет **всё, что появилось после снимка**, в `/etc /root /home /srv /usr/local /opt/ecorpnet /var/spool/cron` и в `~philipp/.ssh`. Удалённые пути печатает на экран.
3. Возвращает содержимое, владельцев и права файлов из снимка: изменённый sudoers, `/etc/shadow`, `authorized_keys` и т.п.
4. Удаляет любой новый SUID/SGID-файл на диске (например `/var/tmp/rb`) и мусор игроков в `/tmp /var/tmp /dev/shm`.
5. Перечитывает systemd, ssh и nginx, затем запускает `ctf-reset`: свежая БД, `/srv/reports`, home pnair, флаги (те же самые).

Как проверить, что всё чисто (вывод должен быть пустым):
```bash
sudo find / -xdev -type f -perm /6000 2>/dev/null | sort | diff - /var/lib/ctf-baseline/suid.list
ls /srv/reports        # dr-test-2015.txt + 3 × headcount-*.csv, ничего больше
curl -sI http://127.0.0.1/ | head -1   # HTTP/1.1 302
```
Сразу после отката nginx пару секунд может отвечать 502, пока стартует gunicorn. Это нормально.

## ⚠ Важно

- **Снимок помнит пароли.** Сменил пароль `philipp` — сразу запусти `sudo ctf-snapshot`, иначе `ctf-restore` вернёт старый.
- То же для любой правки сети, sshd, приложения: правка → `sudo ctf-snapshot`.
- **Не делай снимок, пока на сервере есть следы теста.** Порядок такой: `ctf-restore`, потом правки, потом `ctf-snapshot`.
- Домашний каталог `philipp` (кроме `.ssh`) не трогается: `~/ctf-src` и прочее остаются как есть.
- Снимок лежит в `/var/lib/ctf-baseline/` (только root, ~8 МБ).

## Сценарии

**Перед игрой (финально):**
```bash
passwd                  # сильный пароль для philipp
sudo ctf-restore        # убрать следы своих тестов
sudo ctf-snapshot       # эталон с новым паролем
```

**Во время игры, если кто-то сломал бокс:** `sudo ctf-restore`. Предупреди всех: шеллы упадут, аккаунты в портале пропадут, флаги останутся прежними.

**Во время игры, проверка на «подарки» другим игрокам** (SUID-bash, оставленный в `/var/tmp`):
```bash
sudo find /tmp /var/tmp /dev/shm /srv /home -perm -4000 2>/dev/null
```

**После игры:** `sudo ctf-restore`.

**Новые флаги** (нужен интернет, `provision.sh` ставит пакеты):
```bash
sudo rm /root/.ctf-flags && cd ~/ctf-src && sudo ./box/provision.sh && sudo ctf-snapshot
```
